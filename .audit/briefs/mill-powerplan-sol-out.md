## A. The power question

The independent unit in the registered test is the shared calendar-date
vector, not an event. Sweep 25's SI break-close control has 88 selected events,
49 seated trades, 39 SI scoring days, and 64 dates in the shared-sign family.
The whole break-close lane has 372 selected events. The receipt reports

```text
delta = 726.5625 USD/date
SE = 333.3113 USD/date
t = 2.1798
maxT c95 = 2.2210
simultaneous lower bound = -13.7369 USD/date
```

The implied day standard deviation is `333.3113 * sqrt(64) = 2,666.49`. If the
effect and variance were fixed in advance, the number of independent date
vectors needed merely to cross the current six-line maxT boundary would be

```text
n_cross = (2.2210 * 2,666.49 / 726.5625)^2 = 66.44, hence 67 dates.
```

That is a mechanical crossing, not a powered design. It asks for only a 1.86
percent SE reduction, or a delta increase from `726.56` to `740.30`. The line
was selected for attention after 915 logged trial rows, so both changes are
well inside winner's-curse scale. At the observed effect, current power is
about 48 percent. An 80 percent design under the same maxT boundary needs

```text
n_80 = ((2.2210 + 0.8416) * 2,666.49 / 726.5625)^2 = 126.34, hence 127 dates.
n_90 = ((2.2210 + 1.2816) * 2,666.49 / 726.5625)^2 = 165.24, hence 166 dates.
```

At the present event rate, an independence fiction converts those counts to
92 selected SI events for a mechanical crossing and 174 for 80 percent power,
versus 88 now. Those event counts are not valid sample sizes. Several events
share one impulse, one day, and one seat ledger. A cluster-aware analysis still
has calendar dates as its degrees of freedom.

Shrinking the family does not solve this honestly. A two-line critical value
near sweep 23's `1.8717` would still need about 100 independent dates for 80
percent power. A one-line unadjusted test would need about 84. Choosing either
family now because SI was the winning line is fitted line-shopping. The frozen
EXPLORE split has only 64 shared dates here. HOLD happens to contain 127 SI
days, but the quarantine law permits one HOLD read only for a frozen joint
survivor. This line misses cash, risk, and NKD, so it has no HOLD license.

## B. The SI break-close line

The only clean unit for the existing selector would be an independent-date
replication. Freeze sweep 25's formation, `B_opp >= train top-tercile`,
`I_break >= train median`, the next-bar break-close entry, the frozen outcome,
and the complete seat replay. Register NKD, SI, and their heterogeneity
contrast in one maxT family. Budget at least 100 independent shared dates under
the prior two-line critical value. A family that adds the heterogeneity contrast
will need between that count and the conservative six-line target of 127.

Its letters would use the precedence below and would be exhaustive.

- `BREAKCLOSE-JOINT` requires positive simultaneous matched-control bounds on
  both NKD and SI, both rungs at mean minus two SE, MDD below 1,000, the cap,
  occupancy, and both stresses.
- `BREAKCLOSE-SI-ONLY` requires the SI control bound, SI rung, SI MDD, and SI
  stresses to clear while NKD does not. This records asset heterogeneity. It
  cannot spend HOLD or claim a joint survivor.
- `BREAKCLOSE-KILL` fires when a powered SI upper bound is non-positive, or
  when the SI matched delta is zero or negative, or when the control result
  clears but the executable SI line still fails its rung or MDD.
- `BREAKCLOSE-UNRESOLVED` covers every other result with a positive SI point
  estimate and inadequate power or a failed NKD bound.

That unit should not run now. No independent EXPLORE book exists, and a repeat
on the same 64 date vectors returns the same evidence. NKD is not a nuisance
line to discard. Its `-194.73 USD/date` matched delta and `p=0.9958` are the
preplanned heterogeneity result. Keep the USER timing as a fixed entry lane in
