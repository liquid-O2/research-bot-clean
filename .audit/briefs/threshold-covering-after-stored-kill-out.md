## The one next experiment. Stored-join name rules, dollars only.

One script, one receipt, one read. Peek note in the receipt: candidate-side columns widen; teacher-side license is unchanged from rank-live and capture-gap; kill instrument, cannot promote.

Definitions. Order rows in a cell by (`decision_ts_ns`, `candidate_id`). Recency of a row is `prefix_last_event_ordinal - confirmation_event_ordinal`. A row is a **setter** when its `entry_mid2` strictly beats the running extreme of prior same-side rows in its cell (above the running max for side +1, below the running min for side -1); the first row of a side is a setter by construction. Setter excess is the side-resolved distance beyond that prior extreme, 0 for a side's first row.

Eight preregistered causal lines, closed here, no post-hoc additions. Each picks one CLEAR name per gated cell, prices `cert_close_usd` on READY, and reports the full block: `usd_per_asset_day`, trades, per-trade mean, `max_drawdown_usd`, entry cap, overlap.

1. `ordinal_freshest`: min recency; tie max `decision_ts_ns`; tie smallest `candidate_id`.
2. `ordinal_stalest`: max recency; same tie chain. Direction control.
3. `ordinal_latest_event`: max `confirmation_event_ordinal`; tie smallest `candidate_id`.
4. `extreme_last_setter`: the setter with max `decision_ts_ns`.
5. `extreme_deepest_setter`: the setter with max excess; tie max `decision_ts_ns`.
6. `extreme_first_nontrivial_setter`: the earliest setter that beat an existing prior same-side extreme (excess > 0); fallback earliest CLEAR when a cell has none. The one line walkable at its own moment.
7. `spread_prior_max`: max `spread_prior_usd` among rows with `spread_prior_present == 1`; fallback earliest CLEAR.
8. `spread_prior_min`: min, same guard and fallback.

One family ceiling, exploratory hindsight, labelled in the receipt exactly like the full ceiling: `ceiling_setters`, max `cert_close_usd` among READY setters per cell, entered only when positive. It bounds every setter rule at once and tests whether the 2021 event story transfers to era CLEAR rows.
