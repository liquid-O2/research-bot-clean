## The two complete candidates

### Candidate V. Relicense V0 with a native QRE2FORECAST4 gate

The best version defines a causal 2021 membership law from a native QRF4
volatility field, builds the separate 2021 late store, then runs the frozen B2
teacher-cash lines once. It uses the unspent license and can kill an amended
entry rule out of era.

It loses for three reasons. First, no native QRF4 field preserves the frozen
assetless gate. A per-asset fallback changes the traded days and the policy.
Second, a miss would combine a new gate, a new year, and the B2 chooser in one
number. It could not identify which change failed. Third, 2021 cannot promote,
so even a LIVE would return to the unresolved causal roster and strict replay
work. This is a costly kill-only detour with a weak failure diagnosis.

### Candidate C. B3 age-2400 common-clock strict replay

The best version starts from the first raw CLEAR formation in each locked
cell. It sets one age-2400 clock, admits only formations visible by that clock,
and reads one trusted BBO from the strict raw prefix. It freezes the cell
choice before any suffix work. Exact raw outcomes then enter canonical
chronological replay and one strict `QRE2TABPOLICYBLOCK2`.

B3 pays for its reach with one real persistence change. Learned and frozen
rules need honest tagged trace and block sources. The B2 cap may collapse
because a common quote removes its asynchronous price advantage. Those are
the right risks to measure. They are not reasons to preserve the leaks.

| Criterion | V, native-gate V0 | C, common-clock B3 |
|---|---|---|
| Policy identity | Changes the assetless day gate and retains the B2 chooser | Changes the chooser exactly where causality requires it and preserves locked membership |
| Failure diagnosis | Confounds gate, year, and chooser | Isolates the causal entry clock and exact replay |
| Reach | Kill-only teacher cash | Promotion-grade strict block |
| Forecast exposure | Depends on the exposed mixed-window file family | Opens no forecast file |
| Data cost | New late store plus one teacher read | One raw candidate and EventPack pass |
| Root-cause fit | Adapts around the stopped loader | Removes both B2 future inputs before selection |

Candidate C wins. There is no cheaper stored-label read that can change this
choice. Every late row still carries candidate-relative time and
outcome-conditioned `READY`. Rescoring those rows would measure another batch
cap, not a causal policy.
