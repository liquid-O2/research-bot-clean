# One pass

At a review or wave boundary, collect the complete defect set first. Repair that set as one batch. Run one proof. Then stop that wave. A covering Stage or overnight parent is not a review wave.

Narrow red-green checks inside a single repair are fine. Starting a new review after the first fix, then fixing the next finding, is not.

Codex session `01a034f0` is the anti-pattern.
