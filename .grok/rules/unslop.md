# Unslop

Your reply to the user is a prose surface. Read the `unslop` skill and write the sentence clean the first time. Do not generate slop and clean it later.

Hard bans that keep failing: the long-dash character, a colon used as a mid-sentence connector, curly quotes, decorative emoji, title-case headings, chatbot closers.

Agent-facing docs (skills, briefs, plans) still go through `writing-for-agents`. That is a different bar.
