# DISCRETIONARY_METHOD.md — the portable extraction methodology (for the NKD/HG/SI port)
How the discretionary program works: what data, at what granularity, how decisions are made and recorded, how discretion becomes features, and what three days of running it on IWM proved. Companion to PROGRAM_RECORD.md; laws in DIRECTIVES.md (esp. D-020, D-026/27/28, D-033..037, D-042, D-046).

## 1. THE OBJECT
Entries at CONFIRMED price extremes: a causal ZigZag with an ATR-RELATIVE reversal threshold (max(12bp, 0.11×ATR14) — era-consistent) marks a pivot; it is "confirmed" the second the reversal leg reaches the threshold; the candidate decision moment is 60-120s AFTER confirmation, on the reversal side. (User law D-033: confirm, don't predict; <1%/min value decay for 60s+ was measured.) The full set of such moments per session = the ROSTER (day-complete: never hand-sampled for capture claims, D-036).

## 2. THE DATA A DECISION VIEW MUST CARRY (D-037 completeness law; v4 = 13 sections)
Per candidate, ALL strictly truncated at the decision second, as COMPACT TEXT (~2.5-4k tokens — text beats charts for composing precise interactions):
1. T-MINUS trajectory table: each key quantity at T-30/15/5/1/now + slope + accel + z-vs-clock-norm (norm = median of same minute over prior 60 sessions — "is this loud FOR 10:03am?").
2. Session path + swing chain (LH/HL sequence) + levels (prior day/5d/20d, ATR-scaled) + day context.
3. Per-stream event-arrival rates; episode digest of the WHOLE session (gap-clustered bursts: n, net signed flow, size dist, price travel — lossless, NO minimum-size filters) + itemized exceptions (blocks, through-book, quote-vacuum).
4. RAW final-60-90s ribbon: every print (size, price-vs-quote → certified sign, attached book sizes = side-resolved depth), every NBBO revision, every option print (strike/DTE/right/IV/delta).
5. Flow state: cumulative + windowed certified signed stock flow; option delta-flow; (port: book-EVENT flows — adds/cancels/fills at touch).
6. Vol state: bid/ask vol (IWM: PROXY_VOL surface; port: realized-vol nowcast + range estimators), spike-and-bleed trajectory, vol-of-vol; skew/term where options exist.
7. Greek flows at event grain where options exist (delta/gamma/vanna/charm/vega/vomma... certified signs).
8. Capacity context: runway to close/session-end, distance to magnets, unspent range vs ATR, implied-move bands (fvol), regime tags (day-type by quantile cuts, vol regime).
Every sheet carries a VERSION STAMP naming its sections (the D-042 completeness certificate) — no reader round runs on uncertified views.

## 3. THE PROTOCOL (walk-forward, per era — D-034/D-037)
1. STUDY (outcomes visible, the era being entered): per case — commit a thesis from the causal view FIRST, then unblind, then POST-MORTEM: what confirmed/refuted it, the earliest ex-ante telltale, the deciding interaction. Write named patterns: name, mechanism (who does this and why), exact fields, HOW they combine, regime scope, falsifier.
2. BLIND (that era's later sessions, day-complete): every candidate, chronological, append-only ledger: id  TAKE|SKIP  A|B|C(value class: ≥$1500/700-1500/<$700)  evidence — with calls COMMITTED (git) BEFORE unblinding. Never revise a row.
3. UNBLIND + SCORE mechanically (panel_score pattern): lift = mean(cert of takes)/mean(cert of skips); winner precision; capture-of-oracle under one-position replay. THE ONLY accepted judge.
4. Advance one era; repeat. Patterns are PERMANENT LIBRARY entries with regime-keyed activation (D-031) — an era that kills a pattern's edge doesn't delete it.
Token discipline (D-035/ORCH-7): humans read STRATIFIED SAMPLES + SURPRISE-ROUTED cases (where the model is most wrong = where unnamed patterns hide); machines read everything (census); one-way taint (outcome-seen sessions never re-enter blind sets); used-case ledger enforces novelty.

## 4. FROM DISCRETION TO FEATURES (the codification loop — the actual product)
1. Evidence declarations per call: {primary: exact field+value+read, against, interaction: one sentence, novel}. The "what" must name a sheet line — vague reads are useless.
2. NAME → COUNT (ORCH-1): every named pattern becomes a computable strictly-causal detector, censused over ALL train sessions: fire rate, conditional value, per-quarter stability, MECHANISM DESTRUCTION (neutralize the claimed component; surviving value = wrong mechanism).
3. SELF-AUDIT the reader: per-evidence-family reliability from the reader's own committed calls vs outcomes — the ledger corrects the narrative (measured: my believed-core reads graded near-coin; my 'minor' reads carried the edge).
4. Features are INTERACTIONS in L·P·E·H·R·U (location/pressure/elasticity-response/phase-health/remaining-variance/sensor-reliability), each realized in MULTIPLE modality versions (concept×modality matrix, D-027); textbook single-stream aggregates (OFI/VPIN-class) are BANNED as features.
5. Frozen classical model ONLY takes live decisions (D-040): certifiable, outage-proof; LLM readers teach (features, evidence, audits) — never trade. GRAIN LAW: build candidate features at EVENT grain; minute aggregates killed real signals twice (flow-flip; book-side).

## 10. ENTRY-CONFIRMATION IDEA SET (orchestrator's first-person answer to "what would YOU look at"; each = candidate census, novel formulations, 2026-08-13)
1. OPPONENT-FAILURE EFFICIENCY (the core one): an extreme is confirmed by the OTHER side's attempt-and-failure, not by my side's strength. Measure the retest push's WORK-TO-YIELD ratio — energy spent (volume, book pulls, event intensity) per bp of price achieved. Efficiency collapse on the retest = the move is spent. Refail-clustering was our strongest survivor; this is its physics-grade upgrade at event grain.
2. QUEUE-AGE ASYMMETRY (MBP-1-native conviction sensor): at a true extreme the losing side stops defending — its touch quotes turn young/flickering (short lifetimes, pulls) while the winning side's resting size AGES in place. Old quiet size = conviction; young churning size = uncertainty/spoof. Computable ONLY from event data — IWM never could.
3. THE AUCTION FAILING TO AUCTION (AMT, made causal): price moves to find business; the terminal leg travels on VANISHING participation — marginal volume per price increment collapsing along the leg. Level-conditioned memory: compare against the same level's PRIOR visits.
4. STOP-FLUSH ABSORPTION: the break beyond the prior swing fires the resting stops — a through-price market-order burst. If that flush is ABSORBED (intensity dies within k events, price recovers) the fuel is spent and the reversal is real; if it ignites follow-through, stand aside. The single most discretionary-looking moment, fully computable.
5. CROSS-ASSET NON-CONFIRMATION: an extreme made ALONE is suspect/fadeable — SI printing a new low while HG (and gold context) does not; plus WHO MOVED FIRST at event grain (the follower's extreme fades easier). We own three concurrent event-grain assets; IWM had only RUTW.
6. IGNITION DEMAND: entering 60-120s post-confirmation buys the right to DEMAND evidence — the reversal must already be hiring in that window (flow sign flipped, intensity rising on the new side). No ignition = no entry, regardless of pattern beauty.
7. FUEL MAP (positioning narrative as confirmation): trapped-inventory ahead vs behind — how much forced business (trapped shorts below, longs above) exists to POWER the reversal vs cap it. The reversal needs customers.
8. SESSION-SEQUENCE GRAMMAR: day shapes unfold as sequences (open-drive / morning-extreme / rotation...); score this candidate's position in the session-so-far against a causal nearest-neighbor library of past session shapes (analog retrieval at day grain — cheap, strictly-prior).
Each idea enters as: named detector -> full-population census (fire rate, conditional cert value, era stability, mechanism destruction) BEFORE any model or sheet work — the name->count law.

## 11. WHO IS THE OPPONENT IN THE ALGO ERA (user challenge, orchestrator ruling, 2026-08-13)
The pit-era formulation ("read the human's intent on the DOM") is dead; the reformulation is stronger: infer CONSTRAINT and COMMITMENT, never intent. Three readable classes:
(1) MARKET-MAKING ALGOS = inventory-constrained intermediaries. Read their REACTIONS (widen/pull/refuse-to-restock) as a machine-precise toxic-flow sensor — they built the world's best informed-flow detectors; we read their output. (Queue-age, refill, erosion features.)
(2) EXECUTION ALGOS slicing institutional metaorders = the flows that power our horizon. They CANNOT bluff or walk away (parent must finish) => the most legible signature on the tape: persistent one-sided pressure, participation discipline, hour-scale flow autocorrelation (stronger in the algo era than before — order splitting is universal). "Intent" = parent existence, side, remaining size: footprint questions.
(3) TRAPPED POSITIONS = P&L constraints independent of holder; systematic stops/CTA thresholds are MORE mechanical than old locals. Fuel map + stop-flush families.
EVIDENCE: our surviving blind telltales (refail, book erosion, absorption) ARE opponent-reading features and carried edge on 2022-25 data — the algo-dominated market already validated the reformulation.
CAVEATS AS LAW: we never compete at sub-second (their horizon; ours is minutes-to-hours); exploited signatures decay => every constraint-read enters via census + mechanism destruction + era stability, never as lore. Slogan: pit traders read faces; we read constraints — machines wear constraints more openly than humans wore faces.

## 13. THE FVOL PATTERN GENERALIZED — unique constructions from owned resources (orchestrator, 2026-08-13; user: no forward-capture, use what we HAVE)
The fvol lesson: wherever a static heuristic sits, our own corpus can train a forward model of that quantity. The inventory of such places, ranked:
1. FORWARD-OFFER FORECASTER (the fvol move applied to the day itself): predict TODAY'S offer — certificate dollars available, expected count of $1k-class candidates — from overnight/pre-phase context, updated at phase boundaries. We PROVED offers vary by era/day while patterns hold; a day-offer nowcast is the missing regulator for participation, thresholds, and thin-era posture (D-043). Nobody sets a static top-k when the day's menu is forecastable.
2. SCHEDULE-AWARE SELECTION via the recovered shadow_value label (atlas synthesis): train selection on each candidate's dollar contribution TO THE OPTIMAL ONE-POSITION SCHEDULE (shadow_value), not its standalone value — solves the occupancy bind AT THE LABEL. Our binding constraint, met by a label we already invented and shelved.
3. ENTRY EXECUTION MICRO-TIMER: within the lawful 60-120s post-confirmation window, a learned policy picks the cheapest entry second + limit-vs-market/queue-join choice from book state. On a $25-tick SI, saving half a spread on 2-3 trades/day = $75-150/day — comparable to whole features; measured, low-risk, unglamorous.
