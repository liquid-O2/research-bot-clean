Standing BACKUP PLAN regardless of ladder outcome; hypotheses generator only (D-020 law: never selection/eligibility/certification input).

## Protocol (per batch of ~24 cases; repeatable nightly)
1. DRAW: seeded script; sessions never previously viewed unblinded; RANDOMIZED UNKNOWN category counts (fix of v1's known-mix anchor); times stratified across the day; both sides.
2. RENDER: strictly-causal packs (all panels truncate at decision second — v1 code pattern m[:tidx+1] retained); v2 adds flow/options panels in a SECOND pass per case (call twice: chart-only, then +flow/options) so each data layer's incremental lift on MY calls is measured.
3. CALL: per case, committed pre-unblind: {TAKE/SKIP, conviction 1-5, REASON CODES from the fixed vocabulary, anomaly-notes free text}.
   Reason-code vocabulary v1 (extend by append only): H-LH-structure, H-inert, H-active-trend, E-acceptance-hold, E-rejection-at-level, E-no-evidence-yet, P-rate-regime, P-second-push-decay, P-burst-with/against, L-level-trap, L-mid-air, R-day-type-drive/range/compression/cascade, T-chasing(>2-5m), T-patient-window.
4. UNBLIND + LEDGER: append to calls.tsv (case id, codes, call, conviction, outcome net/MAE/stop, session, time). Never edit past rows.
5. MINE (each ~100 cases): per-code and per-code-PAIR hit rates + value capture; conviction calibration curve; my blind hit rate = the running HUMAN CEILING estimate per case class.
6. HIDDEN PATTERNS: anomaly notes clustered; any recurring pattern gets (a) a name, (b) a mechanism sentence (who does this and why), (c) a strictly-prior constructive formula proposal -> feature family candidate via the L-P-E-H-R-U registration law + concept x modality matrix (D-026/D-027).
7. OUTPUT: DISCRETION_NOTES.md (the "proper notes" — what works, what combinations, with counts), updated per batch; feature proposals -> design/ pins.
