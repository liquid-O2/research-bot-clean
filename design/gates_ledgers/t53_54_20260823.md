# Gates: ticket 52 — the regime conditioner

Scope: on HG the price-extreme score is a coin flip in rich cells (0.502) and
informative in cheap ones (0.309), confirmed against its null. So the live
question is "will this cell be big?", asked CAUSALLY at the cell's own start.

The constraint that decides the whole ticket: T19's Spearman 0.82 used REALIZED
phase range, which is known only at phase end. A conditioner must be readable
from the FIRST event's own row, before the cell has revealed itself.

- [x] G1: the target is the CELL's value (cell-best y), a between-cell quantity —
        not a within-cell rank. This is the frame no scan has ever used
  EVIDENCE: Target is cell-best y, a BETWEEN-cell quantity. Every prior scan in this program ranked names WITHIN a cell; this frame has never been used, which is why a signal this size was sitting unmeasured.

- [x] G2: every column scored from the FIRST event's row only, so the
        conditioner is causal at the moment it would have to fire
  EVIDENCE: Scored from the FIRST event's row in each cell, chosen by minimum formation time, so the conditioner is readable at the moment it would have to fire. This is the causal version of ticket 19's Spearman 0.82, which used REALIZED phase range and is therefore unusable live.

- [x] G3: survivors hold on TRAIN and THRESHOLD in the same direction
  EVIDENCE: Survivors required |rho| >= 0.30 on TRAIN and >= 0.20 on THRESHOLD in the SAME direction. NKD 28 survivors led by w1800_event_rate +0.523/+0.468; SI 54 led by tclock path variation +0.548/+0.295; HG only 3.

- [x] G4: the T44 control is structural — any survivor is reported beside its
        entry-price twin, because side x entry price is already refuted
  EVIDENCE: The activity family is not a price quantity, so the T44 entry-price trap does not apply to it. What DOES need flagging is the clock family: phase_remaining_sec (+0.423 HG, +0.653 SI) and phase_index (+0.591 SI) correlate with cell size because more time means more room, which is capacity not regime. Flagged in the verdict, not promoted, and the finding rests on the non-clock family.

- [x] G5: a null: shuffle cell-best across cells, so the correlation floor from
        sample size is visible beside every survivor
  EVIDENCE: Null floor is the 97.5th percentile of |rho| under 200 shuffles of the target: 0.271 HG, 0.262 NKD, 0.383 SI. The SI floor is high because it has only 32 TRAIN cells, and that is stated rather than hidden.

- [x] G6: verdict written — either named conditioner candidates, or
        `no_causal_regime_signal`, which would close the two-regime idea cheaply
  EVIDENCE: VERDICT: a causal between-cell richness signal EXISTS on NKD and SI from columns already on this matrix - activity, sweep speed, path variation, prior range - holding TRAIN and THRESHOLD in the same direction. NOT established that it converts to dollars, because a conditioner that flags a rich cell does not say which name to take there, and rich cells are exactly where the picker is chance. HG has almost no regime signal and the highest rung. Written to design/entry_reset/T52_REGIME_20260823.md.

  EVIDENCE: All five arms cashed on TRAIN and one THRESHOLD read. EXTREME_ALL wins everywhere (HG $1,014/$947, NKD $875/$940, SI $1,465/$1,061); every split arm loses to it; CHEAP_ONLY is catastrophic, which confirms the rich cells carry the money.   EVIDENCE: The conditioner separates cell value 1.83-2.00x on TRAIN and 1.86-2.08x on THRESHOLD - nine of nine, WIDER out of sample. The split failed for a precise reason: T50 measured degradation in cells that TURN OUT rich, this splits on cells PREDICTED rich, and under that split the picker is BETTER in rich cells on NKD (0.261) and SI (0.220). Predicting value is not locating failures. The conditioner survives as a capital-allocation signal.
