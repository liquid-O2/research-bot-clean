# Wave 2. Prepare every change in parallel

[Back to overview](overview.md)

## Goal

Complete all non-destructive discovery, caller migration, code rewriting, recovery binding, and cutover planning in 5 hours 45 minutes. No deletion or data move occurs in this wave.

## Ownership lanes

**Control plane.** Owns cleanup modules, cleanup tests, the test registry, and dispatcher. It resolves classification, planning, receipt, and verification defects.

**Authority and history.** Owns root narrative drafts, authority mappings, source-span coverage, evidence maps, and onboarding fixtures. It does not edit production code or data manifests.

**Live architecture.** Owns replay, shared research analysis, corpus interfaces, their callers, and behavior tests. It keeps `tabular_atomic.py` and `tabular_model_io.py` unless direct evidence disproves their depth.

**Recovery and data.** Owns recovery groups, raw and corpus manifests, link rewrite plans, data caller inventories, and identity proofs. It does not move or delete bytes.

Assign exact path ownership before dispatch. A path has one writer. Facts that cross lanes merge through registries and receipts after lane work stops.

## Work

- Classify every eligible path. Uncertain rows remain `unresolved` and therefore kept.
- Build complete caller inventories for imports, commands, build rules, CI, source references, links, registries, and generated verifiers.
- Draft `README.md`, `START_HERE.md`, and `PROJECT.md` with disjoint fact ownership.
- Map every retired historical source span to a current fact, exact receipt, memory event, frozen exception, or Git blob.
- Bind each proposed removal to one recovery, rebuild, identity, or semantic-migration proof.
- Prepare the raw-root move and all 945 known absolute link rewrites as one transaction.
- Prepare corpus relocation as a separate transaction with a full content manifest and one configuration seam.
- Deepen replay behind one trace interface. Migrate twin callers before removing private cross-module access.
- Give current probes one typed research-analysis interface. Remove sibling `probe_*` imports after caller migration.
- Keep `build_corpus` as the corpus interface. Split implementation only by owned knowledge.
- Classify neural symbols as live contract, retired receipt stub, obsolete implementation, or persisted loader before any removal.
- Prepare dead code, tests, tools, and dependency rows only after current liveness evidence is complete.

## Boundary integration

Stop all lane writes. Merge registries and drafts through one integrator. Collect the complete Wave 2 defect set across all lanes. Apply one repair batch with disjoint fixes in parallel when safe.

Then run one full verification and one 16-worker full audit. Run the audit alone. It must finish within 30 minutes. Verify every row and compile one canonical, deterministic apply plan.

## Exit criterion

Every eligible path is classified. Every destructive row is `ready`, recovery-bound, and present in one canonical apply plan. All remaining uncertain paths are explicit keeps. No lane owns unfinished work. The boundary proof passes.
