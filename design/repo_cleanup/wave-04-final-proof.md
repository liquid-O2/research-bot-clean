# Wave 4. Prove and report the final repository

[Back to overview](overview.md)

## Goal

Finish in 3 hours 30 minutes. Prove the real retained system from a clean checkout, publish exact measurements, and retire closed cleanup machinery.

## Work

- Freeze the candidate scope. Prepare final onboarding, metrics, the completion receipt, the memory event, and cleanup retirement actions.
- Exercise native Entry V2, Python recovery, corpus rehearsal, chronological replay, recovery, raw links, seal refusal, authority, and onboarding.
- Collect every defect from the complete sweep before editing.
- Apply one repair batch and rerun affected lanes.
- Publish final documents, the receipt, the memory event, and cleanup retirement through one repository transaction.
- Create a clean checkout of that exact tree. Make external recovery unavailable and attach only retained local data and declared generated inputs.
- Run independent verification lanes in parallel when they have disjoint outputs and state.
- Run stateful hook canaries, cleanup commands, and shared-output builds one at a time.
- Run the final full dispatcher once.
- Run two final audits and compare their retained-registry digests.
- Make no repository write after final proof begins.

## Metrics

Report before and after tree structure, files, directories, symlinks, logical bytes, allocated bytes, production LOC, test LOC, documentation LOC, generated LOC, vendor LOC, dependency counts, data classes, removed paths, moved paths, rewritten references, and reclaimed space.

Separate raw data, sealed data, live derived data, current outputs, caches, evidence, and recovery objects. Record protected roots only as opaque names and counts.

## Verification

Follow [testing.md](testing.md) in its final acceptance order. Final proof uses real supported commands and real retained artifacts. A compile-only or unit-only result is insufficient.

If the full proof fails, collect every failure before the repair starts. Use the reserve for one complete repair batch. Never relax lossless or protected-root rules to force completion.

## Exit criterion

All gates pass with no abandoned lossless gate. Two audits propose no action and produce the same digest. The repository is clean. The final report contains the requested measured comparison and links to its machine receipts.
