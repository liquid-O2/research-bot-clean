# Collaboration and continuity

## How a new agent starts

Read, in order:

1. `INDEX.md`
2. `PROJECT_CONTRACT.md`
3. `PROJECT_MEMORY.md`
4. `PLAN.md`
5. `knowledge/propositions.tsv`
6. `knowledge/evidence.tsv`
7. the exact active task card and decision record for the assigned gate

Then state in one paragraph:

- the exact scientific object;
- current disposition and blocker;
- the next bounded deliverable;
- what will not be touched.

Do not infer project truth from hidden conversation context or from the
newest artifact.

## Work decomposition

Parallel lanes should be disjoint:

- authority/provenance and restore proof;
- production implementation;
- independent refute-first review;
- documentation/knowledge extraction;
- evaluator or cached analysis when it cannot contend with the main run.

One lane owns each output path. Shared payload scans are consolidated. Before
launch, publish exact source SHA, output path, worker count, memory/FD budget,
launcher, and stop condition.

## Reporting contract

Lead with:

1. what is now known;
2. whether it is causal, leaked, hindsight, diagnostic or blocked;
3. whether it advances the economic contract;
4. the next decision and measured ETA.

Hashes support the statement; they do not replace it. If an experiment
changes no decision, explain why it is still necessary or stop it.

## Review contract

Reviewers distrust reports and recompute the decisive claim. They inspect:

- exact source/spec/input/output/evaluator bindings;
- roster and clock causality;
- typed dependency masks and denominators;
- positive controls and deliberate failures;
- output identity and publication atomicity;
- scientific meaning and scope of any null.

P0s are consolidated where possible. A reviewer may green only the bounded
next action, not an implied larger program.

## Continuity and transcript law

The readable conversation ledger in Git is navigation and accountability.
Raw session bytes are authority only through the encrypted private vault and
its prefix manifests. Live sessions are frozen at byte cutoffs and marked
continuing; later suffixes must prove prefix continuity.

Malformed streamed records are preserved byte-for-byte. Readable extraction
tolerates fragments and deduplicates repeated completed items by stable
message/item identity while recording every source byte disposition.

Historical local Claude files may be archived and cited. Operator amendment
2026-08-10 (E_GOVERNANCE_OPERATOR_AMENDMENT_V1): Claude operates the program
(orchestrator + implementer/review lanes per FINAL_PLAN §15); the former
no-Claude-service clause is struck on the record.

## Decision discipline

- Reversible, in-scope work proceeds without delay.
- New payload, contaminated folds, forward escrow, destructive cleanup and
  remote publication require the governing gate.
- Destructive operations use explicit target manifests and restore proofs.
- If an assumption changes the scientific object or external authority,
  stop and register a decision rather than guessing.
