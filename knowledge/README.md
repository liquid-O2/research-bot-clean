# Knowledge ledgers

The ledgers provide mechanical closure between source material and active
claims.

- `propositions.tsv` records one proposition per row with status and scope.
- `evidence.tsv` binds each claim to exact spec, code, ordered inputs, output,
  evaluator and controls.
- `conflicts.tsv` keeps contradictory eras visible until resolved.
- `research_assets.tsv` inventories papers, notes and access/license status.

Migration is incomplete while any captured source segment, message,
proposition, evidence object, conflict or research asset lacks an explicit
disposition.
