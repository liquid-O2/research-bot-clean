# THE DEFICIT LEDGER — a standing diagnostic harness

`PORT-M2-DEFICIT-V1` · `engine/port_m2/deficit_ledger.py` · tests
`engine/port_m2/test_deficit_ledger.py` (56/56 green)
Outputs: `DEFICIT_LEDGER.tsv` · `DEFICIT_FIXLIST.tsv` · `DEFICIT_CONTRACT.tsv` ·
`DEFICIT_CALIBRATION.tsv` · `DEFICIT_SESSIONS.tsv`
Receipt: `artifacts/cache/port/m2/deficit/deficit.receipt.json`
(`params_hash` in every TSV header).

This is not a census. It is an **instrument that stays**: hand it any scored
judge and it answers, in dollars per session and per (era, asset, regime cell),
*which named improvement would close the gap to the bars, and by how much.*

---

## WHAT IT DOES

A **judge** is a score table + a policy shape. The table is keyed by `cid` or by
the committed matrix `row` and carries any of `{score, take, value_usd,
entry_sec, exit_sec}`; the policy says how the table becomes takes (top-N per
selection unit / keep-fraction / an explicit take column), which contract the
values live under, and which sessions the judge was responsible for. Nothing
else about a judge is known or needed — which is why the m3 model arm, fifteen
hand takes and a walk-forward gate all decompose through one code path, and why
the pretrained / GRPO / frontier arms will need **no new code at all**:

```
deficit_ledger.py --score-table TABLE.tsv --policy POLICY.json
```

### BLOCK A — the fixed-contract ladder (additive)

Nested one-position replays over the judge's own frozen contract. Increments are
non-overlapping dollars and **sum exactly to each session's recoverable pool**
(asserted on every judge, every run):

| level | component | improvement type |
|---|---|---|
| v0 | realised | — |
| +1 | `SEL_WRONG_SIDE` — taken losers whose wall-pair mirror paid | **validity** |
| +2 | `SEL_WRONG_MOMENT` — right episode, better second existed | **moment layer** |
| +3 | `SEL_WRONG_MEMBER` — better same-class episode that day | **ranking** |
| +4 | `PARTICIPATION` — qualified-but-untaken seats at its own threshold | **throughput / abstention** |
| = ceiling | `RANKING_RESIDUAL` — what no named repair reached | **scoring headroom / foresight** |
| above ceiling | `OPPORTUNITY` — bar above the day ceiling | **generation / coverage** |

Per session: `bar − realised = OPPORTUNITY + recoverable − surplus`, and the
five ladder components sum to `recoverable`. Because any ladder order is a
choice, every component **also** carries its order-free **standalone** value
(that repair alone, from the judge's own takes) — which is what THE-FIX-LIST
ranks beside the additive share.

### BLOCK B — the contract-change deficits (not additive; D-029 reserved)

Two independent one-dimensional changes, both priced on **every** seat from the
roster path skeleton (`c_c_roster._skel_query` — the object the m1 tau tensors
were built from, and the object that produced the matrix certificate):

* `EXIT` — hold the $900 wall, move the exit mark (30s / 60s / 120s / session
  close vs the phase close in force);
* `RISK` — hold the phase-close exit, move the wall width ($300 … $2,400, and
  no wall).

The headline is the best **single fixed rule** for the whole (era, asset) cell —
a contract you can write down — with the per-seat hindsight optimum kept beside
it as the outer bound only.

### CALIBRATION (diagnostic)

Stated-vs-realised by score tier on the judge's own ordering, plus the dollars
recoverable by re-thresholding that same ordering.

## INSTRUMENT RECEIPTS (all green, all mechanical)

* **The replay is the replay.** `deficit_ledger.replay` reproduces
  `m3_walk.replay_rows` seat-for-seat, dollar-for-dollar and forfeit-for-forfeit
  on five random 4,000-take draws. It exists only because block B must override
  an exit second, which that function cannot express.
* **The day ceiling is the committed day ceiling.** Equal to
  `provenance/port_m3/PER_SESSION.tsv`'s `day_ceiling_usd` on **3,097/3,097**
  sessions.
* **The m3 arm reproduces ERA_CURVE exactly.** v0 equals
  `ERA_CURVE.tsv`'s `usd_per_session` in all 8 eras and equals `PER_SESSION.tsv`'s
  `realised_usd` on **3,097/3,097** sessions. (The scores are regenerated by
  calling `m3_walk.run_era` itself; the matrix was rebuilt on 2026-08-14 16:06
  with the 18 D-078 teacher columns, *after* the committed 12:26 walk, so the
  producer drops the `teacher_evidence` group through m3_walk's own
  `--drop-groups` control arm — which is what makes ERA_CURVE reproducible.)
* **The teacher arm reproduces the corrected pooled record.** v0 = **$4,506.25**
  over the 15 sealed takes; own-rate = **$300.4167/trade**.
* **Block B prices on the object that built the certificate.**
  `c_c_roster.certificates` on the roster skeleton reproduces the matrix
  `cert_close_usd` and `cert_peak_usd` exactly on 600 sampled rows across all
  three assets, 0 mismatches.
* **Hand-computed arithmetic fixture.** A five-candidate synthetic day with the
  side / moment / member increments read by eye (+1,400 / +400 / +1,100, residual
  +1,200, sums to the ceiling).
* **RED-FIRST, as ordered.**
  * **ORACLE judge** (the day ceiling's own DP schedule): realised == ceiling;
    selection deficit **0.000000**; ranking residual **0.000000**; participation
    **0.000000**; and no *standalone* repair finds a dollar either.
  * **RANDOM judge** (uniform scores, same policy shape): **selection dominates**
    — **$1,313.80**/session of selection (61 % of its whole block-A total) against a
    *negative* $136.17 participation; its calibration table is flat at every tier,
    as a random score must be.
  * The oracle's selection deficit is exactly zero while the random judge's is
    $1,313.80 — the instrument *separates* the two, it does not merely score them.
* **One-command contract, proved.** A cid-keyed table the test writes from
  scratch decomposes end-to-end with no judge-specific code and passes the
  additivity identity.

**Two defects this harness found in its own first run, both fixed and both
fixture-locked:** (1) a repair that *breaks the day's schedule* was being booked
as a deficit — the oracle fixture scored a perfect judge at −$1,302/session until
each repair was made per-session monotone; (2) alternative wall widths were being
priced only on the seats the $900 wall had already stopped — pure survivorship,
which returned a false "tighten to $300, +$88/session" in every era. Both are
named in the code where they were fixed.

**What it says.** The m3 arm's deficit is **ranking, not side and not moment**.

participation is **negative**: the score's own threshold admits 631,203 rows and

## BLOCK B — the contract, across all three judges

| judge | peak capture (winners) | giveback / seat | best fixed exit | exit $/sess | exit oracle bound | best fixed wall | risk $/sess | risk oracle bound |
|---|---|---|---|---|---|---|---|---|
| m3 arm | **0.392** | $803 | `SESS_CLOSE` (13/24 cells), else `CLOSE` | 245.50 | 1,436.90 | scattered | 55.61 | 136.60 |
| teacher | 0.707 | $818 | `H30` / `CLOSE` | 58.33 | 514.10 | `W300`/`W600` | 90.91 | 191.80 |
| oracle | 0.580 | $876 | `CLOSE` / `SESS_CLOSE` | 9.49 | 77.70 | `W900` (24/24) | **0.00** | 0.00 |

Two findings, both consistent with the delay census's closing pointer:

1. **The exit contract leaves ~$1,437/session/asset on the table at the oracle
   bound and a fixed clock collects $246 of it.** Winners realise **39 %** of
   their own peak and give back **$803 a seat** — but no fixed horizon recovers
   it, because the peak second is not a clock. The improvement type is therefore
   **a state-dependent exit rule**, not a faster or slower one; a clock-shaped
   exit programme is already priced here at a quarter of the deficit.
2. **Wall width is noise, not a lever.** The best fixed wall for the m3 arm is
   scattered across `W300 / W600 / W900 / W1200 / W1500 / W1800 / W2400 / NO_WALL`
   with no two consecutive (era, asset) cells agreeing, and the whole effect is
   $55.61/session. The oracle judge — which walls nothing — keeps `W900` in
   24/24 cells and shows exactly $0.00. The $900 wall is not what is costing the
   programme money. **Both are D-029 user-reserved and are reported, never
   acted on.**

## THE ONE SENTENCE

**Across three completely independent judges — a walk-forward GBT, a human at
maximum effort, and a decidability gate on a different trade class — the deficit
has the same shape: it is RANKING (which episode of the class, that day), never
the SIDE and never the SECOND; throughput is a lever only for the judge that
under-trades; and of the two contract levers, the stop is worth nothing and the
exit is worth real money that no clock can collect.**

```bash
lab/run.sh port-m2-deficit -- python3 engine/port_m2/deficit_ledger.py --run
python3 engine/port_m2/deficit_ledger.py --judge m3,teacher,gate

        --score-table SCORES.tsv --policy POLICY.json            # ANY new judge
python3 engine/port_m2/test_deficit_ledger.py                    # 56 checks
```

`SCORES.tsv` needs `cid` (or `row`) and any of `score`, `take`, `value_usd`,
`entry_sec`, `exit_sec`. `POLICY.json` is `{"name", "unit", "topn"|"keep_frac",
"deployable", "contract", "scope", "seats_per_day", "bar_usd"}`. The pretrained,
GRPO and frontier arms need nothing else.
